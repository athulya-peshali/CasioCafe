# Casio Cafe System ☕📱

An Android-based Cafe Management & Ordering Application paired with complete Business Analysis documentation. This project covers the full software development lifecycle—from requirements gathering and system design to Android development and database integration.

---

## 📌 Project Overview

The Casio Cafe application streamlines day-to-day cafe operations by providing dedicated interface flows for both customers and administration staff. Key capabilities include order tracking, administrative control, promotional management, and automated user notifications.
