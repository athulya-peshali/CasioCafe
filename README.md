# Casio Cafe System ☕📱

An Android-based Cafe Management and Ordering Application accompanied by comprehensive Business Analysis documentation. This project covers the complete software development lifecycle—from requirements engineering and process modeling to mobile application development and database integration.

---

## 📌 Project Overview

The **Casio Cafe** application is designed to streamline cafe operations, customer ordering, and administrative management. The system provides dedicated workflows for customers, staff members, and system administrators, featuring order tracking, promotional management, payment validation, and administrative access control.

# 📄 Business Analysis Deliverables 
The Business_Analysis directory contains the complete specification document (PROJECT DOCUMENT - CASIO CAFE.pdf), detailing:

Requirements Engineering: Functional and non-functional requirements for standard users, staff members, and super administrators.

Process & Workflow Modeling: Business process flows for order placement, payment verification, and automated staff credential generation.

User Access Control: Role-Based Access Control (RBAC) matrix defining distinct permission boundaries between staff and super admin roles.

Data Modeling: System data flows, entity relationships, and database schema mappings for backend integration.

# 🛠️ Tech Stack & Methodologies
